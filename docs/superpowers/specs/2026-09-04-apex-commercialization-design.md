# Apex Promoter 商业化第一阶段设计

## 目标

将 Apex 宣传台从官方产品展示与内容演示工具，升级为“Apex 系列免费使用、自有产品付费创作”的本地优先 iOS 应用。Apex 系列是本应用开发者自研并用于自身推广的产品线，免费用户可以直接用它完成从生成到复盘的全流程；用户建立并推广自己的品牌和产品时才需要一次性内购解锁。

## 用户与权益

- 免费用户：直接使用内置 Apex 系列产品（含 WordPulse）完成生成文案、导入素材、导出发布包、加入发布队列和记录复盘；不可新建自有品牌/产品，不可为自有产品创建推广项目。
- 付费用户：在免费能力之上解锁自有品牌与产品管理、用自有产品生成和排期内容。
- 权益由 `EntitlementStore` 统一提供，免费额度边界由 `ProductAccess` 统一判定，UI 不直接判断 StoreKit 交易细节。启动时以及回到前台时刷新交易状态，购买成功、恢复购买和退款/过期都会更新本地状态。
- 内购采用 StoreKit 2；商品 ID 从配置注入，未配置商品或网络不可用时展示明确的离线状态，不伪造已购买权益。

## 核心流程

免费路径：`选择 Apex 系列产品 -> 选择平台 -> 生成并编辑 -> 校验 -> 平台预览 -> 保存 -> 导出/分享 -> 发布记录 -> 复盘`

付费路径：`查看付费功能 -> 购买/恢复 -> 建立自有品牌与产品 -> 选择自有产品 -> 生成并编辑 -> 校验 -> 保存 -> 导出/分享 -> 发布记录`

项目使用 SwiftData 持久化，新增 `PromotionProject`、`ProjectAsset` 和 `PublishAttempt`，现有 `ContentDraft` 作为项目内的一次内容版本保留。每个项目记录创建者本地标识、产品来源、目标平台、内容类型、更新时间和发布状态。

## 平台适配器

首阶段平台集合：小红书、微信公众号、微信朋友圈、知乎、视频号、抖音、快手。

每个平台实现 `PublishAdapter`，声明支持的内容类型、标题/正文/标签限制、媒体规格和可用动作：复制文案、导出图片/视频、系统分享、打开平台 App/网页、官方 API 直发。首阶段默认实现复制、导出和系统分享；直发只有在平台官方授权、审核和接口条件满足后启用。任何直发失败都保留导出包和失败原因。

## 内容与合规

- 保留现有本地生成器和校验器，生成结果必须带产品来源和生成时间。
- 发布前必须通过校验并由用户明确确认；阻断项需要覆盖说明才能继续。
- 不收集或保存平台密码、Cookie、Session、设备指纹或私有登录页面。
- 视频平台使用视频脚本、封面和素材导出；不在后台模拟自动发帖。

## UI 结构

免费态首页保留 Apex 产品浏览；新增“我的项目”入口和付费解锁页。免费态即可对 Apex 产品生成、导出、排期和复盘；自有产品相关操作（新建品牌、添加产品、为自有产品创建项目）统一显示权益说明并跳转购买。付费态增加自有产品工作区并显示专业版标识。

## 错误处理与测试

- 购买失败、恢复失败、网络不可用、素材格式不兼容和平台分享失败均提供可重试操作，不丢失已保存项目。
- 单元测试覆盖权益状态转换、免费额度边界（Apex 系列免费 / 自有产品需解锁）、项目保存/加载、平台适配器格式约束、导出包生成和校验阻断。
- UI 测试覆盖免费用户对 Apex 产品的完整可用性、自有品牌与产品入口的锁定态、购买后创建项目、编辑保存、平台预览和系统分享入口。
- 首阶段验收以本地稳定闭环为准：没有购买时可以完整推广 Apex 系列产品，但不能新建自有品牌/产品或为自有产品创建项目；购买恢复后权限正确；七个平台均能生成符合声明的分享/导出动作；无平台凭证字段。
