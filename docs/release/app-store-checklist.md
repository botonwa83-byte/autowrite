## 内购商品

- Product ID: `com.kingtop.apexpromoter.premium`
- 类型: Non-Consumable（非消耗型，一次性买断）
- 显示名称: Apex 宣传台专业版
- 审核说明: 内置 Apex 产品仅用于免费观摩和示例；购买专业版后，用户可创建自己的品牌、产品推广项目并导出/分享内容。
- 在提交应用版本时同时提交该内购商品，确保商品状态可供审核。

## 隐私与权限

- 照片库权限用途：导入产品截图制作推广素材。
- 通知权限用途：在用户设置的发布时间提醒打开应用确认分享。
- 不使用跨应用跟踪，不出售用户内容。
- App Privacy 问卷按实际行为声明：本地保存的品牌/产品/项目内容、StoreKit 购买历史、用户主动访问的官网公开内容。

## 截图与文案

- 截图至少覆盖：首页概览、Apex 产品免费观摩、品牌中心、内容生成、项目排期/分享、效果复盘。
- 避免把“专业版”描述成订阅，不出现自动续费、月费或年度订阅措辞。
- 明确说明内置 Apex 产品是示例内容，用户购买后管理自己的产品线。
- 描述中不承诺下载量、提分结果或平台流量结果。

## 审核前验证

- Release 构建不包含强制 Premium 状态或 UI 测试启动参数。
- 新用户可浏览内置 Apex 产品，不购买也能查看示例。
- 未购买时创建自有产品/导出操作显示购买引导。
- 本地 StoreKit 配置验证购买、恢复购买、重复启动后的权益保持。
- 真机验证照片导入、通知拒绝后的降级行为、系统分享和视频导出。
- 清理测试数据后重新安装，再验证升级安装保留本地数据。
